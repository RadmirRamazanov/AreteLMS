Система управления обучением со встроенным проверяющим кодом. Пользователи регистрируются, просматривают блоки задач, отправляют решения на Python, SQL или HTML и отслеживают прогресс по пяти тематическим разделам.

## Стек

- **Язык:** Python 3.11+
- **Веб-фреймворк:** Flask 3.0 
- **ORM:** Flask-SQLAlchemy 3.1 + SQLite 
- **Аутентификация:** Flask-Login 0.6 
- **Хэширование паролей:** Werkzeug `generate_password_hash` / `check_password_hash`
- **Фронтенд:** шаблоны Jinja2, HTML5/CSS3 + Boostrap/JS
- **Запуск кода:** `subprocess` с таймаутом

## Структура проекта

```
arete-lms/
├── app.py              # Фабрика приложения (create_app) и точка входа
├── config.py           # Все константы конфигурации, читаются из env
├── models.py           # Модели SQLAlchemy: User, Task, Submission; словарь BLOCKS; seed_tasks()
├── services.py         # SubmissionEvaluator — запуск и проверка решений
├── routes/
│   ├── __init__.py
│   ├── api.py          # Blueprint REST API, префикс /api
│   └── web.py          # Blueprint серверного рендеринга страниц
├── templates/          # HTML-шаблоны Jinja2 (base, index, lms, block, task, login, register)
├── static/
│   ├── css/            # Стили по страницам
│   └── js/             # Скрипты по страницам
├── instance/           # Файл SQLite БД — создаётся при запуске, не коммитится
└── requirements.txt
```

## Маршруты

### Веб (серверный рендеринг)

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/` | Главная — обзор блоков с прогрессом |
| GET/POST | `/register` | Форма регистрации |
| GET/POST | `/login` | Форма входа |
| GET | `/logout` | Выход (требует авторизации) |
| GET | `/lms` | Редирект на `/lms/theory` |
| GET | `/lms/<block_key>` | Список задач блока |
| GET | `/block/<block_key>` | Альтернативный вид блока |
| GET | `/task/<task_id>` | Страница задачи и форма отправки решения |

### API (`/api`)

| Метод | Путь | Авторизация | Описание |
|-------|------|-------------|----------|
| GET | `/v1/blocks` | — | Все блоки с количеством задач |
| GET | `/v1/tasks` | — | Все задачи; фильтр `?block=` |
| GET | `/v1/tasks/<id>` | — | Метаданные одной задачи |
| GET | `/v1/me` | требуется | Профиль текущего пользователя |
| GET | `/v1/me/progress` | требуется | Количество решённых задач по блокам |
| GET | `/v1/me/submissions` | требуется | Последние 50 посылок |
| POST | `/submit` | требуется | Отправка решения |
| POST | `/v1/upload-code` | требуется | Загрузка файла с кодом (макс. 1 МБ) |

## Типы задач и проверка

| Тип | Способ проверки |
|-----|----------------|
| `python` | Запуск через `python3` subprocess против JSON тест-кейсов; частичный балл по доле пройденных тестов |
| `answer` | Точное сравнение строки с `expected_output` |
| `sql` | Проверка наличия ключевых слов в тексте ответа |
| `html` | Проверка наличия ключевых слов в тексте ответа |

Таймаут subprocess: 10 с (настраивается через `SUBPROCESS_TIMEOUT` в `config.py`).

## Блоки задач

| Ключ | Название | Тематика |
|------|----------|----------|
| `theory` | Теория | Математика, системы счисления, олимпиадная логика |
| `algorithms` | Алгоритмы | Сортировки, поиск, динамическое программирование, теория игр |
| `data` | Данные | SQL, анализ данных, структуры данных Python |
| `backend` | Бэкенд | REST API, Flask, алгоритмы со stdin/stdout |
| `frontend` | Фронтенд | HTML, CSS, JavaScript, валидация форм |

## Переменные окружения

| Переменная | Обязательна | По умолчанию | Описание |
|------------|-------------|--------------|----------|
| `SESSION_SECRET` | Да | хардкод-заглушка | Flask `SECRET_KEY` — в продакшене задать реальное значение |
| `PORT` | Нет | `5000` | Порт, на котором слушает сервер |
| `FLASK_DEBUG` | Нет | `0` | Установить `1` для режима отладки с авторелоадом |

Скопируйте `.env.example` в `.env` и заполните значения перед запуском.

## Запуск

```bash
# 1. Создать и активировать виртуальное окружение
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Настроить переменные окружения
cp .env.example .env
# Отредактировать .env — как минимум задать SESSION_SECRET

# 4. Запустить сервер разработки
python app.py
```

При первом запуске приложение создаёт SQLite-базу и заполняет её всеми задачами автоматически.

## База данных

SQLite-файл хранится в `instance/arete_lms.db` (создаётся Flask-конвенцией при запуске). Чтобы использовать другую БД, замените строку подключения в `config.py` на валидный SQLAlchemy URI. Схема создаётся автоматически через `db.create_all()`.

## Безопасность

- `SESSION_SECRET` должен быть длинной случайной строкой в продакшене. Встроенная заглушка **не подходит для реального использования**.
- Запуск пользовательского кода через `subprocess` — потенциально опасная операция. В любом публичном деплое сервер должен работать в изолированной среде (контейнер, sandbox).
- Загружаемые файлы проверяются по расширению и ограничены 1 МБ; принимаются только `.py`, `.txt`, `.sql`, `.html`.
